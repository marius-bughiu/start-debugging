2026 年 7 月 22 日にリリースされた Claude Code 2.1.218 は、`/code-review` が実行される場所を変更します。長いレビューを会話の中に展開して、あなたの実際の作業を上へ、視界の外へ押し出すのではなく、レビューはバックグラウンドのサブエージェントとして実行されるようになりました。あなたの会話はあなたのものとして残ります。レビューはわきで進行し、見たいときに確認できます。

## 2.1.218 で変わること

見出しは changelog では小さくても、日々の利用では大きいものです。`/code-review` はバックグラウンドのサブエージェントとして実行されるようになりました。ここから 3 つのことが導かれます。

レビューの出力があなたの会話を埋め尽くさなくなります。コードレビューは多くのファイルにまたがって数十件の指摘を生み出すことがあります。以前はそのすべてがメインのトランスクリプトに流れ込み、作業していたスレッドを埋もれさせていました。今ではそれはサブエージェントの中に収まります。

積み重ねられた slash コマンドはレビューの対象として保たれます。`/code-review` を他のコマンドの後ろにキューイングしても、レビューはバックグラウンドに移る際に対象を見失うことなく、何を調べるべきかを引き続き把握しています。

ナビゲーションに安全策が加わりました。エージェントビューで `Esc` を押すと、レビューがバックグラウンドに移された元の会話へ戻るので、あなたは自分の位置を見失いません。同じリリースでは、左矢印キーが取り消し不可のまま会話をひそかに破棄していた問題も修正されました。今では確認を求めます。

## 2.1.215 で始まった変化の締めくくり

これは何もないところから出てきたわけではありません。数ビルド前、2.1.215（7 月 19 日）は Claude が `/verify` と `/code-review` を独自に実行することをやめました。必要なときにあなたが呼び出します。2.1.218 は同じ考え方をリサーチへ広げます。`/deep-research` は手動で呼び出したときにのみ開始するようになり、Claude はもうそれを独自に起動しません。

まとめると、メッセージは一貫しています。長く、騒がしく、コストの高い skills はオプトインであり、本流の外にあります。それらは自動的に発火せず、あなたが発火させても、あなたのセッションを乗っ取ることはありません。これは、2.1.198 以降サブエージェントが[デフォルトでバックグラウンド実行される](/ja/2026/07/claude-code-2-1-198-subagents-run-in-the-background-by-default/)ことの背後にある同じ発想です。

## fork コンテキストの skills はデフォルトでバックグラウンド実行になります

skills を書くなら知っておく価値のある付随的な変更があります。`context: fork` の skills はデフォルトでバックグラウンド実行になりました。これは、隔離されたコンテキストを立ち上げるあなた自身の skills について、`/code-review` の挙動と一致します。

fork の skill をフォアグラウンドに保ちたい場合は、frontmatter のフラグで skill ごとにオプトアウトします。

```yaml
---
name: my-review-skill
context: fork
background: false
---
```

真偽値のパーサーも 2.1.218 でより寛容になりました。skills とプラグインの frontmatter の真偽値について、`yes`、`no`、`on`、`off`、`1`、`0` が `true` と `false` に加えて受け付けられるようになり、大文字小文字は区別されません。

## なぜこれが重要なのか

メインの会話は、あなたが考える場所です。そこへ出力の壁を流し込むものは、トークンだけでなくあなたの注意も奪います。レビューとリサーチをバックグラウンドのサブエージェントへ移すことで、トランスクリプトは読みやすいまま保たれ、遅い作業をあなたをブロックせずに走らせられます。`/code-review` が画面をあふれさせるという体の記憶があるなら、それを更新してください。実行し、作業を続け、終わったらエージェントビューを確認するのです。
