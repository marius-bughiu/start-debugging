ここ 2 週間の Claude Code のリリースは、エージェント群にどこまで自由を与えるかをめぐる綱引きでした。バージョン 2.1.213 は入れ子を完全に取り上げました。2026-07-24 に登場したバージョン 2.1.219 は、それを具体的な数値とともに返します。サブエージェントはデフォルトで深さ 3 まで、自分自身のサブエージェントを生成できるようになりました。以前は 1 でした。

## デフォルト値は 2 週間で 2 回変わった

[changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) の記述は率直です。「サブエージェントはデフォルトで深さ 3 まで入れ子のサブエージェントを生成できるようになりました（以前は 1）。入れ子を無効にするには CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 を設定してください」。

この経緯は追う価値があります。動作は 3 回変わっているからです。v2.1.172 から v2.1.216 までは、サブエージェントは 5 層まで入れ子になり、その上限は変更できませんでした。次に 2.1.213 が[暴走するサブエージェント群に上限を設定](/ja/2026/07/claude-code-2-1-213-caps-runaway-subagent-fleets/)し、デフォルトを深さ 1 に下げました。つまりサブエージェントはまったく委譲できず、補助役を立てるよう頼んでも自分で作業をこなしていました。2.1.219 は 3 で落ち着きます。

つまみ自体は変わっておらず、動いたのはそのデフォルト値だけです。1 層だけのフラットな委譲に戻すには、`settings.json` で固定します。

```json
{
  "env": {
    "CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH": "1"
  }
}
```

深さ 3 はきりのよい数字ではなく、意図された数字です。レビューのファンアウトに必要なのはまさにこの形です。メインの会話がレビュアーを生成し、レビュアーが指摘ごとに検証役を生成し、各検証役はさらに絞り込んだ調査を委譲できます。深さ 1 では、この形が 1 つのコンテキストウィンドウの中ですべてを順番に処理する単一のサブエージェントに潰れていました。

## 対抗策としてのサイズガイドライン

ブレーキなしで入れ子を再開放すれば、2.1.213 が解決した問題を再現するだけです。そこで同じリリースがブレーキを追加しました。動的なワークフローはデフォルトで中程度のサイズガイドラインを使い、15 エージェント未満を目標とします。そしてこのガイドラインは `/config` のトグルだけのものではなくなりました。専用の設定キーがあります。

```json
{
  "workflowSizeGuideline": "medium"
}
```

任意の設定ファイルに書けば、`/config` の行は自動的に隠れます。実行中のワークフローのステータス行にも現在のサイズが表示されるようになったため、稼働中にどのガイドラインで動いているかを確認できます。ただしこれは助言的なものです。モデルが目指すエージェント数を形づくるだけで、厳格な上限ではありません。実際の上限は、これまでどおり同時実行数とセッションあたりのサブエージェント数の制限です。

## デフォルトで遮断するネットワーク許可リスト

今日設定しておく価値のあるもう 1 つの変更が `sandbox.network.strictAllowlist` です。デフォルトでは、コマンドが許可していないドメインを初めて必要としたときに、サンドボックスは確認を求めます。管理された配布では `allowManagedDomainsOnly` によって、確認せずに遮断することがすでに可能でした。今はどの設定ファイルからでもデフォルト遮断にできます。

```json
{
  "sandbox": {
    "enabled": true,
    "network": {
      "strictAllowlist": true,
      "allowedDomains": ["github.com", "*.npmjs.org"]
    }
  }
}
```

無人実行では、これこそ欲しい設定です。誰も答えない確認はハングと同じであり、入れ子が戻ったことで、それに突き当たりうるプロセスは増えています。

2.1.219 のその他の変更点として、Claude Opus 5 (`claude-opus-5`) がデフォルトの Opus モデルになり、1M コンテキストと $10/$50 per Mtok の高速モードを備えます。また Opus 4.7 は高速モードから完全に外れました。
