## Что действительно объявил автор

В [первоначальном объявлении](https://www.reddit.com/r/csharp/comments/1qgbjo4/saas_educational_free_and_opensource_example_cv/) Mihnea Radulescu описал коммерческий SaaS, разработка которого началась в ноябре 2025 года. Позже сервис был закрыт, а проект предложен как учебный пример под MIT. Автор назвал .NET 10, ASP.NET Core, Blazor Server, Azure Cloud и Azure AI Foundry. Задача — отбор кандидатур. Это описание автора, а не независимая проверка точности или готовности к эксплуатации.

Кешированная копия прежнего GitHub README описывает извлечение PDF через Document Intelligence и сравнение с вакансией моделью семейства GPT-5. В ней перечислены EF Core 10, хранилища и базы Azure и вариант самостоятельного размещения, всё ещё требующий ресурсов Azure AI; инструкции называли `gpt-5-mini`. Это не подтверждает текущий код, доступность модели, современные требования или результаты тестов. Недоступный репозиторий в этой проверке не собирался и не проходил аудит кода.

## Полезные вопросы проектирования

Разделение извлечения документов и обработки моделью стоит оценить отдельно. [Документация layout-модели Document Intelligence](https://learn.microsoft.com/en-us/azure/ai-services/document-intelligence/prebuilt/layout?view=doc-intel-4.0.0) описывает извлечение текста, таблиц и структуры. Проверьте результат на своих документах до передачи модели. Извлечение с последующим вызовом LLM само по себе не доказывает наличие RAG-архитектуры.

Храните настройки отдельно от кода и проверяйте действительно необходимые значения. Исторические рекомендации README по user secrets и переменным окружения — не законченный план защиты production. [Документация Secret Manager](https://learn.microsoft.com/en-us/aspnet/core/security/app-secrets?view=aspnetcore-10.0) поясняет, что user secrets предназначены для разработки и не шифруются. Переменным окружения тоже нужен контроль доступа. Прежний иллюстративный `Program.cs` удалён: это не проверенный код репозитория, а свойства C# `required` не обеспечивали проверку обязательных значений во время выполнения через `ValidateDataAnnotations()`.

В качестве доступного учебного маршрута используйте [Generative AI for Beginners .NET v2](/ru/2026/03/generative-ai-beginners-dotnet-v2-dotnet10-meai/) и связанные материалы по документам и интеграции моделей, а не недоступный проект как шаблон развёртывания.
