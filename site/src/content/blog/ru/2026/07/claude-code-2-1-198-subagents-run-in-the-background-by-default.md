Claude Code v2.1.198 вышел 2026-07-01 и меняет модель выполнения субагентов по умолчанию. До сих пор запуск субагента (инструмент Task, пользовательские агенты, команды агентов) блокировал главный цикл: вы делегировали часть работы, родительский агент затихал, и вы ждали возврата дочернего, прежде чем что-либо ещё двигалось дальше. Начиная с 2.1.198, субагенты по умолчанию выполняются в фоне, и главный агент продолжает работать, пока они выполняются.

## Почему блокировка была неправильным значением по умолчанию

Смысл субагента в изоляции. Вы поручаете ему самодостаточную задачу (обойти каталог, проверить утверждение, набросать миграцию) с собственным окном контекста, чтобы родитель не утонул в дампах файлов. Но если запуск субагента замораживает родителя до его завершения, вы теряете вторую половину выгоды: параллелизм. Два независимых запроса, которые могли бы выполниться одновременно, выполнялись один за другим, и затраты реального времени были суммой, а не максимумом.

Фоновое выполнение по умолчанию исправляет это. Родитель распределяет работу и продолжает в главном потоке. Когда дочерний агент завершается, его результат возвращается как уведомление, на которое вы можете отреагировать, а не как барьер, за которым вы ждали. Для всего, что поддаётся декомпозиции, это разница между конвейером и очередью.

## Фоновые агенты, которые доводят работу до конца

Вторая половина выпуска касается того, что фоновые агенты делают по завершении. Если фоновый агент выполнял работу с кодом в git worktree, он больше не останавливается, чтобы спросить, что делать с diff. Он автоматически делает commit, push и открывает draft PR, а затем отчитывается.

Это реальное изменение в рабочем процессе. Старый цикл был таким: запустить агента, подождать, просмотреть предложенные им изменения, а затем самому сделать commit и push. Новый цикл такой: запустить агента, продолжать работать и обнаружить draft PR, ожидающий проверки, когда он появится. Состояние черновика служит страховкой: ничего не сливается само по себе, но обвязки между "агент закончил" и "я могу проверить настоящий PR" больше нет.

```bash
# Before 2.1.198: foreground subagent, main loop blocks until it returns.
# You then stage and push its changes by hand.

# 2.1.198+: subagent runs in the background, you keep working, and a
# code-writing background agent lands its work as a draft PR itself:
#   [background] agent "refactor-auth" finished
#   -> committed, pushed branch agent/refactor-auth, opened draft PR #482
```

Поскольку значение по умолчанию изменилось, стоит перечитать любую автоматизацию или документацию, которая исходила из того, что субагенты синхронны. Шаги, неявно опиравшиеся на то, что субагент завершится до выполнения следующей строки, теперь должны явно ожидать результата.

## Остальное в 2.1.198

Ещё два пункта входят в тот же выпуск. Claude in Chrome теперь общедоступен, что выводит инструменты управления браузером из стадии предварительной версии. И появилась новая skill `/dataviz` для построения графиков и дашбордов. Выпуск также усиливает сетевую устойчивость к временным ошибкам и исправляет пакет багов в фоновых задачах, командах агентов и Remote Control, тот же курс на надёжность, что продолжился в [исправлениях фоновых сессий из 2.1.200](/ru/2026/07/claude-code-2-1-200-renames-default-permission-mode-to-manual/).

Если вы хоть немного опираетесь на субагентов, заголовок прост в формулировке и велик на практике: они больше не заставляют вас ждать. Полные заметки есть в [changelog Claude Code](https://code.claude.com/docs/en/changelog).
