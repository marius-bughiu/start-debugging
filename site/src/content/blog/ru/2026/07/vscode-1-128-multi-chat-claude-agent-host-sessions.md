VS Code 1.128 вышел 8 июля 2026 года, и главное здесь не функция Copilot. Главное в том, что одна agent-host сессия Claude теперь может держать сразу несколько связанных чатов, у каждого свой журнал, заголовок и выбор модели, и все они сгруппированы под одной родительской сессией. Режим agent-host работает на Claude Agent SDK от Anthropic, запущенном прямо внутри VS Code, и этот выпуск превращает его из однопоточного опыта в нечто ближе к рабочему верстаку.

## Почему одна сессия с несколькими чатами важна

До 1.128 изучение двух подходов к одной задаче означало либо разрушение контекста при развороте в середине потока, либо запуск совершенно новой сессии с потерей общей настройки. Несколько чатов решают это. Вы можете ответвиться от предыдущего хода, оставить исходный чат нетронутым и выполнять оба параллельно. Каждый чат отслеживает свою модель, так что вы можете столкнуть более дешёвую модель с более сильной на одной и той же задаче и сравнить diff бок о бок, не покидая сессию.

Это привязано к режиму agent-host. Включите его в `settings.json`:

```json
{
  "chat.agentHost.enabled": true
}
```

После этого окно **Agents** становится центром. Новые чаты появляются в разделе **Chats** под родительской сессией, а фокус на окно вы наводите командой `workbench.action.openAgentsWindow`.

## Quick chat снимают требование рабочего пространства

Второе изменение, убирающее трение, это quick chat. Теперь вы можете начать разговор из окна Agents, не открывая сначала папку. Это звучит незначительно, пока вы не осознаете, как часто хотите спросить у агента что-то, не имеющее отношения к открытому сейчас проекту, а раньше для этого приходилось открывать временное рабочее пространство. Quick chat поддерживаются только agent-host сессиями, поэтому они используют тот же переключатель `chat.agentHost.enabled`.

Субагенты тоже упомянуты: agent-host может делегировать субагенту, и вы просматриваете журнал субагента только для чтения, так что делегирование не загрязняет журнал родительского чата.

## Использование собственных ключей модели

Есть также экспериментальная настройка для команд, которые хотят направлять запросы через своего провайдера моделей, а не по встроенному пути:

```json
{
  "chat.agentHost.byokModels.enabled": true
}
```

Поддержка BYOK помечена в 1.128 как экспериментальная, так что относитесь к ней как к предварительной версии, а не как к тому, что стоит стандартизировать в команде на этой неделе. Сочетайте её с `chat.byokUtilityModelDefault`, если хотите управлять тем, какая модель обрабатывает более дешёвые служебные вызовы.

Завершая выпуск, Copilot Vision стал общедоступным, так что вставка, перетаскивание или сброс изображений и PDF в Chat больше не предварительная версия, а агент может обращаться к этим вложениям через вызов инструмента.

Часть с несколькими чатами стоит попробовать первой. Если вы уже запускаете agent-host Claude в VS Code, включите `chat.agentHost.enabled`, откройте окно Agents и ответвите чат вместо того, чтобы перезапускать его. Полные заметки есть в [примечаниях к выпуску VS Code 1.128](https://code.visualstudio.com/updates/v1_128).
