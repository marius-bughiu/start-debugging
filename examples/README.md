# Article examples

These projects replace unavailable external examples linked from the blog. Each folder contains its own run instructions. The site builds downloadable archives from the explicit file list in `manifest.json`; build outputs, local caches, and credentials are excluded.

| Example | Purpose |
| --- | --- |
| `unsafe-accessor` | Check constructors, member access, and the limited readonly-field demonstration |
| `unsafe-accessor-benchmarks` | Compare five observable call paths with BenchmarkDotNet |
| `generic-type-definition-benchmarks` | Reproduce generic-type lookup measurements on selected runtimes |
| `windows-screenshot` | Capture a Windows virtual desktop or run a synthetic-image self-test |
| `react-native-two-columns` | Run the restored layout in Expo or export it for the web |

Code is covered by the repository's MIT license. Article text keeps its existing content license. Verification results and platform limits are recorded separately; compiling a project is not evidence that every platform or performance claim was tested.
